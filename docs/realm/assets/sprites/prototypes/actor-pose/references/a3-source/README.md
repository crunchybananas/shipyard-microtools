# A3 Attachment Source

`cargo-crate.png` is the transparent, project-bound painted source for the A3
equipment interchange proof. `cargo-crate-keyed.png` is the built-in
image-generation result retained as provenance.

The source was generated on 2026-07-29 with the established Realm builder
component sheet and A2 source-parts contact as style references. The prompt
requested one original frontier oak supply crate in three consistent
orthographic views, fixed upper-left lighting, deliberate painted pixel
clusters, a perfectly flat `#00ff00` background, no shadow, no text, and no
character. The installed imagegen chroma-key helper removed the sampled
`#03f905` border with soft matte and despill.

components remain in the sheet so later down/up/side direction work can bind
