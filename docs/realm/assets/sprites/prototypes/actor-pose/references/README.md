# Actor Pose Component-Concept Provenance

These four PNGs are isolated RFC 0002 prototype inputs. They are not registered
runtime art and are not a hidden generation step in the compiler.

## Generation

Date: 2026-07-18

Tool: built-in OpenAI image generation, using Realm's locked guard and builder
identity proof art as visual references.

Prompt intent, summarized:

- preserve the same guard or builder identity, warm painted pixel-era palette,
  clothing, face, and equipment language;
- arrange cleanly separated front, back, and side heads, torsos, arms, legs,
  and role equipment on a solid `#ff00ff` key color;
- use a neutral component presentation rather than an animation strip; and
- do not treat the generated sheet as authority for pose, body scale, root,
  feet, sockets, frame order, or direction phase.

The `*-keyed.png` files preserve the generated key-color result. The companion
PNGs remove only that exact key background and retain RGBA component pixels.

## Authority boundary

Candidate A hash-locks and crops these concepts for painted texture, palette,
and silhouette cues. JSON clips, anchors, sockets, and the compiler own the
animation. The current concepts still co-author identity and base garments, so
they do not yet prove arbitrary `VisualDNA`/`GarmentKit` interchangeability.
That is an explicit blocker for canonical adoption, not compatibility work to
be preserved.
