# Candidate B source

This directory is the network-free source authority for RFC 0002 candidate B.
The compiler treats the JSON files as immutable, hash-recorded inputs.

- `visual-dna.json` owns role proportions, identity silhouettes, garments, and
  palettes.
- `action-clips.json` owns the shared eight-beat phase, contacts, gait, carry,
  and asymmetric work arc.
- `views.json` owns orthographic projection, four view rotations, explicit
  depth ordering, and the socket contract.

The generated raster is intentionally a prototype, not runtime art. Geometry
owns roots, feet, phase, joints, sockets, and occlusion. A deterministic
posterized/faceted treatment supplies the soft pixel-cluster presentation.
