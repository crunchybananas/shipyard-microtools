# Attic

Retired Shipyard-era apps, preserved for reference. Nothing in this
directory is deployed — the GitHub Pages site is built from `docs/` only.

These micro-apps were part of the original Shipyard proof/attestation
tier (proof capture, attestation tracking, reputation graphs, ship
forecasting, and related experiments). That tier was retired when the
project pivoted; the apps are kept here intact for historical reference
and possible future salvage.
